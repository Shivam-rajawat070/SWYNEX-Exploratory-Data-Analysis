# SWYNEX-Exploratory-Data-Analysis

Task 2 of my Data Analyst Internship with SWYNEX Technologies.

## Objective
Perform Exploratory Data Analysis (EDA) on the cleaned sales dataset from Task 1 to identify trends, patterns, and anomalies.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## What I Did
- Checked data structure, data types, and missing values
- Identified anomaly: "Unknown" customer entries
- Created a Revenue column (Quantity × Price)
- Calculated summary statistics (Total Revenue, Average Order Value, Average Rating)

## Key Insights
1. **Revenue by Category** – identified top-performing product categories
2. **Monthly Revenue Trend** – tracked how revenue changed across the year
3. **Top 10 Cities by Revenue** – found highest revenue-generating cities
4. **Payment Mode Usage** – analyzed share of each payment method
5. **Rating Distribution** – studied spread of customer ratings
6. **Correlation Heatmap** – examined relationships between Quantity, Price, Rating, and Revenue

## Files
- `02-task.ipynb` – full analysis notebook with code, charts, and outputs
- `cleaned_sales_dataset.csv` – dataset used for analysis
